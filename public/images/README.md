# Project photographs

Drop real photographs of the company's own land and completed work here, then
list them in `src/data/projects.ts`. Until an entry exists there, the site
shows a drawn placeholder instead.

Deliberately no stock photography is bundled: on a real-estate site, generic
building photos presented alongside a company's name read as that company's
work. Only use pictures of actual Nexus Realty Ventures sites.

Suggested: JPEG or WebP, at least 1200px on the long edge, under ~400KB each.
